# DeepSeek 鲸鱼娘 · 可动模型（v8）

按原插画做的网页版可动模型。**每个像素都取自你那张原图**（举手那套手臂来自对齐后的差分图），所以待机状态和原画几乎逐像素一致。

## 这一版（v8）修的是什么（"更怪了"那一轮）

上一版把尾巴拆成"腿前 + 腿后"两片来治叠层，结果片与片之间接不上，尾鳍像悬空；手臂层也混进了 AI 图的白底和另一只胳膊。这版把结构重做了：

| 现象 | 真正的原因 | 改法 |
|---|---|---|
| 尾鳍和尾巴对不上、像两块拼的 | 尾巴被拆成 `Tail_Back`/`Tail` 两片，各自形变，交界处永远错位；补被腿挡住的那段用的是"两侧颜色中位插值"，直接糊出灰条纹方块 | **回到一条尾巴**：从原画重新抠（颜色取种子 → 形态学闭运算把浅色肚皮整块包进来），被腿挡住的那段用"最近可见尾巴像素"延展补齐（取离边缘 4px 的核心像素当种子，不会沾上抗锯齿白边）。整条尾巴**一层**，画在腿后面——和原画的遮挡关系完全一致 |
| 尾巴整体发灰发白、周围一圈白块 | 抠图时 alpha 写成了"内部只有 47% 不透明"，整条尾巴是半透明的，背景透上来就发灰；底图 `Base_Body` 里尾巴位置还留着一块"拟合背景" | alpha 直接用**原画 `cut.png` 的 alpha**（边缘抗锯齿与原画一致）；底图里尾巴像素整块清掉，改由 `Tail` 层提供 |
| 举手时腰侧还挂着一截原画的叉腰手臂 | 底图 `Base_Body` 里就有叉腰手臂，举手时只把袖子层隐藏了，底图那截照旧露着 | 拆出 **`Base_NoArm`**（底图去掉手臂），举手时整张切换过去；上面的 AI 躯干本来就是不透明的，正好盖住挖空的部分 |
| 手边一块白方块 / 手腕后面挂着头发丝 | 举手手臂是按"与原图的差异"切的，切完又把内部所有空洞填满 → AI 的白底、手指缝都被填成了不透明 | 重切：差异掩膜 + **剔除 AI 白底**（B−R≥10 且亮度≥180）+ 只补"洞里确实有内容"的空洞，手指缝保持镂空；再按手画的多边形切掉另一只胳膊的残片 |
| 裙子左边一块灰白三角形 | AI 生成举手图时，把原画叉腰手臂的一小块袖口/手腕也画进去了 | 在 AI 图上把那块补掉（inpaint），再切躯干层 |

顺带：`Torso` 的 alpha 改成"原画轮廓 ∪ AI 图里非白底的内容"，举手时袖子不会被原画轮廓裁掉；边缘 22px 的融合区在手臂位置不再混回原画（否则举着手时肩边会露出一条原画袖子）。

顺带清掉的：

- 腿层和大腿处那条**竖直浅色接缝**（竖直方向闭运算填窄缝，只填宽度 <40px 的）。
- 眼睛层改成**只在眨眼时显示**（它是整块矩形，常驻会在脸侧露出矩形边），其余时间由底层原图提供眼睛。

## 上一版（v6）修的是什么（残留 / 没补的地方）

你说「白袜子有点模糊、周围还有残留」和「尾巴动时挡在尾巴下面那一块没补上」，这两件事是同一个根源：**尾巴层是从矩形截图里抠的**，边缘那一圈半透明的抗锯齿像素既不是尾巴也不是腿。

| 现象 | 原因 | 改法 |
|---|---|---|
| 白袜子边缘发糊、周围一圈白雾 | `Legs` 的 alpha 是**羽化过的半透明边**，底下补齐的尾巴条纹会从半透明处透出来，看着像糊了 | 腿层改成**二值 + 1px 羽化**，蝴蝶结、蕾丝这类细节交给底图 `Base_Body` 原样兜住 |
| 尾巴离开后原位露出空白/灰块 | 尾巴原来是"只切看得见的部分"，被腿挡住的那一段根本没数据 | 先算出尾巴的**完整形态**（颜色判据 + 横向闭运算跨过一条腿），只把落在**腿上**的那两段当桥接补进去 |
| 尾巴基部换成背景后露出尾巴残影 | 底图 `Base_Body` 还留着尾巴的像素 | 尾巴区域整块替换成**二维多项式拟合的背景**（背景本来就是一层竖直渐变，拟合残差 <2/255），比 inpaint 干净（inpaint 会把腿白和尾深蓝糊成灰） |
| 两腿之间夹着一块不动的小白块 | 腿层里有第三块连通域（裙子内衬/腿间背景）被当成腿 | 腿层只保留面积最大的**两块**（左腿、右腿），其余全丢 |
| 尾巴拖出一条灰线 / 飘小碎点 | 腿边缘的紫灰描边被颜色判据误判成尾巴，形成 1~2px 细条 | 尾巴掩膜加 3×3 开运算 + 丢掉 <500px 的碎块 |

顺带还修了两个画面上的硬伤：

- **帽檐下缘一条黄绿锯齿**：生成图把帽子下方的刘海画成了黄绿色，被一起切进了 `Hat` 层。现在按颜色剔除 + inpaint 补 RGB，双层清理后干净了。
- **举手时手腕处一块灰扇形**：`ArmUp_Lower_L` 的右上角有一块几乎全透明的鬼影（alpha 10~25），叠起来就是一把灰扇子。清掉 alpha<25 的像素并重羽化。

## 上一版（v5）修的是什么（尾巴 / 腿）

你说「尾巴一动，整个脚那块都跟着动，一节一节地动」和「一部分动、一部分还留在原地」，是**两个不同的 bug 叠在一起**：

| 现象 | 真正的原因 | 改法 |
|---|---|---|
| 尾巴一动，腿跟着动 | `Tail` 层里根本混着**两条腿**（白丝袜整块），而且被放在腿的上面 —— 尾巴一转，腿就跟着转 | 重新按"人体 − 尾巴"抠出 `Legs` 层；`Tail` 只保留鲸尾本体 |
| 尾巴动，一部分留在原地 | `Leg_L`/`Leg_R` 原来是**矩形截图**，里面含一段尾巴；那段不会动，尾巴移开后它还在原地 | `Legs` 改成按轮廓抠（不再含尾巴），底图 `Base_Body` 也把尾巴区域抹成背景 |
| 尾巴像"一整节硬掰" | 尾巴原来只有一个枢轴：根部还有 35% 的常数转角（根部一直在转），尾尖转得最多，中间几乎不弯 | 改成**两段关节 + 行波**：根部权重严格为 0，中段一个关节、尾尖一个关节，尾尖还带 0.95 弧度相位滞后 |

顺带把尾巴的遮挡关系改回原图的样子：**腿在尾巴前面**（之前弄反了，尾巴盖住了腿）。

另外修掉几个会直接看出来的小 bug：

- `Hand_L`（左手）原来不跟手臂骨骼走 → 手臂一动、手留在原地，腕部断开。现在手挂在前臂上。
- 底层头部原来不跟头部组旋转 → 摇头时下巴处露出「第二张脸」的轮廓。现在底层上半身跟着头一起转。
- 两套手臂原来用 0.1 秒淡入淡出 → 中间帧是**半透明的手臂**（能看见背景透过来）。改成 1 帧硬切，看不见了。
- 顺手把转体幅度收小（4.5°→3°），把下层残影压到看不出。

## 怎么打开

**只想看它动** → 打开 `预览.html`：三段动画直接内嵌在页面里，打开就自动循环播放，不依赖 WebGL、不依赖视频解码器（动画 WebP，Chromium / Safari / 微信内置浏览器都能播）。

**想自己玩** → 双击 `index.html`（Chrome / Edge）。

- 鼠标在画面上移动 → 她转头看你
- 底部按钮：待机 / 打招呼 / 伸懒腰 / 摇摆 / 眨眼 / 戴帽子
- 右上角「叠加原图对比」→ 半透明叠原图，没重影就说明对得上
- 右上角「参数」→ 8 个滑杆（AngleX/Y/Z、EyeOpen、ArmL、ArmR、Tail、BodyZ），名字与 Cubism 参数一致

## 现在能做什么

| 功能 | 实现 |
|---|---|
| 转头、歪头 | 24 层网格逐顶点形变，头部组绕颈枢轴旋转 |
| 眨眼 | 眼睛绕上缘压扁，最低 4% 不会压成一条线 |
| 呼吸 | 全身绕脚点缩放 + 上下浮动 |
| 摆尾 | 两段关节（尾根 / 尾中）+ 沿尾长传播的行波，根部锁死、尾尖滞后 |
| 头发飘 | 后发绕根部，越往下权重越大 |
| **挥手** | 第二套手臂差分（上臂+前臂+手），前臂绕肘摆 ±26° |
| **双手举** | 左右同时切换，配躯干补全区 |
| **戴帽子** | 独立 Hat 层，可随时戴/摘 |

## 两套手臂

原图双手叉腰，手臂和裙子贴死，纯靠蒙皮做不出大动作——一转就破洞。所以做了差分：

- `Arm_Upper_L/R` + `Arm_Lower_L/R` + `Hand_L`：原图叉腰姿势（待机）
- `ArmUp_Upper_L/R` + `ArmUp_Lower_L/R`：举手姿势（打招呼 / 伸懒腰）

举手那套不是手画的：拿原图当参考生成"只改手臂"的图，用 6000 个 ORB 特征点做 RANSAC 仿射，对齐回原图坐标系（误差 <1px），再按"与原图的差异"精确切出整条手臂——**黑袖 + 白蕾丝袖口 + 前臂 + 手**，一路到袖根。脸、头发、裙子、尾巴、丝袜全部仍是原图像素。

## 还看得出来的小瑕疵（不藏着）

分层是从一张**平涂插画**上切出来的，不是从 Live2D 那种已经拆好的 PSD。所以有几处天生难补：

- **两腿之间那条白**：原图本来就在腿间露出背景白，分层后边缘是硬的（原图这里是柔和过渡），贴得近能看出一点。
- **腰部左侧**（叉腰那只手下方）有一小块颜色略偏蓝灰，是躯干层与裙摆的接缝，放大 3 倍能看到。
- **锁骨/腋下的蕾丝**在抬手的过渡帧里会有一瞬间轻微错位——两套手臂素材的蕾丝花边不是同一笔画的。
- 手指边缘有 1px 的抠图白边（放大到 300% 才看得见）。
- 尾巴被腿挡住的那两段是**算出来的**（不是画出来的），贴到 300% 会看出是平滑的带状填充，没有鳞片纹理。原图里这两段本来就被腿盖住，正常看是看不见的。

## 还没做的（先说清楚）

- **衣服只有一套**。原图只有这身女仆装，换装得另外画三套（配色/裙型/领口），有图我就能拆层换。
- **没有 3/4 侧脸和侧身**。原图只有正面，转头是网格变形模拟的 ±12°，不是真转。要真转得补画侧面和中割脸。
- **没有 .moc3**。这个格式是 Cubism Editor 独占，没有任何第三方能生成。这份文件的作用是"能直接跑、能看、能改"，不是取代 Cubism。
- **帽子只有一顶**。想换款式，做一张"同角色 + 另一顶帽子"的图，对齐后切出帽区替换 `tex/Hat.png` 并改 `meta.js` 里的坐标。
